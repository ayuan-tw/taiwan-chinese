# 澄詞 タグ設計

## 4つの分類

- 学習メモ：忘れやすさ、発音注意、課題由来など、復習方法に関するタグ
- 場面・話題：旅行、夜市、WOS、仕事など、使う状況に関するタグ
- 使い方：台湾での自然さ、会話上の役割、似た表現との比較に関するタグ
- 文法・意味：品詞、文法機能、意味分類に関するタグ

Ver.6.7.0では、「あゆあんの口ぐせ」を学習メモ、「話題転換・間つなぎ・言い直し」を使い方、「文具・計算」を場面／話題として扱う。

未登録の新しいタグは「文法・意味」に入る。分類を変えたい場合は `js/data-model.js` の `TAG_GROUPS` に追加する。

## 表記の統一

読み込み時に次の表記を自動で統一する。元データや既存の学習履歴は変更しない。

- `接続` → `接続詞`
- `天氣` → `天気`
- `台湾旅行` → `旅行`

表記ゆれを追加する場合は `js/data-model.js` の `TAG_ALIASES` に登録する。

## 絞り込み

同じ一覧で複数タグを選択した場合は AND 条件とする。

例：`#会話` と `#何度も質問した` を選ぶと、両方のタグを持つ項目だけを表示する。

単語・句型・慣用說法の選択状態は別々に管理し、「解除」または「全部表示」でリセットする。

## 共通の学習範囲

ホームの「今回の学習範囲」では、項目種別（單字・句型・慣用說法）とタグを組み合わせる。選択結果は端末に保存し、意味4択・瞬間作文・音から中文4択・音から中文入力で共有する。音からクイズは、共通範囲のうち單字だけを使う。
